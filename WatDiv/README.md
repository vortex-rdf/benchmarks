# WatDiv — Waterloo SPARQL Diversity Test Suite

> **Status: planned** — no setup or results yet.

[WatDiv](https://dsg.uwaterloo.ca/watdiv/) (Aluç et al., University of
Waterloo) is a synthetic benchmark designed to cover a much wider range of
**structurally diverse basic graph patterns** than earlier benchmarks. It is
one of the most relevant workloads for vortex-rdf, since it exercises exactly
what the store implements natively: triple-pattern matching and BGP joins.

- **Data**: generated by the WatDiv data generator around an e-commerce-like
  schema; scale factor 1 ≈ 100K triples, commonly run at 10M–1B triples.
- **Queries**: 20 basic templates in four shape classes — **L**inear,
  **S**tar, snowflake-shaped (**F**), and **C**omplex — instantiated with
  random placeholders; plus extended stress-test workloads.
- **Tooling**: C++ data/query generator, available from the project page or
  [github.com/dsg-uwaterloo/watdiv](https://github.com/dsg-uwaterloo/watdiv).

## Planned setup

1. Build the WatDiv generator; generate data at one or more scale factors
   (e.g. 10M and 100M triples) into `WatDiv/data/` (git-ignored).
2. Serialize to `.vortex` (dictionary + default layouts) and to the artifact
   formats of the comparison engines (COTTAS, HDT, Oxigraph, …).
3. Instantiate the 20 query templates; run through the shared
   rdflib-store harness (see [DBBench](../DBBench/) for the driver pattern).
4. Commit curated results to `results/`.
